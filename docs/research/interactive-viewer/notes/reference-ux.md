# Reference interaction design: spreadsheet sort & filter (Excel and Google Sheets, desktop web)

Scope: shipping desktop behavior as of 2026. Excludes VBA/macros, Power Query, pivot tables. Each section distinguishes confirmed UI facts (with sources) from inference.

## 1. Exact structure of the auto-filter dropdown in Excel (sections, order, controls)

### Takeaway
Excel's per-column AutoFilter dropdown combines one-click sorts, clear/filter-by-color commands, a type-specific condition submenu, a search box, and a checkbox value list with OK/Cancel; the exact top-to-bottom ordering below is partially inferred since no primary source enumerates the full order.

### Cited Findings
- AutoFilter is toggled via Data > Filter; each header gets a drop-down arrow button, and clicking it opens "a list in which you can make filter choices" — "Microsoft Excel displays either Number Filters or Text Filters in the list" depending on column data type ([Source](https://support.microsoft.com/en-us/excel/quick-start-filter-data-by-using-an-autofilter)).
- The dropdown's value section is "a list box with a complete listing of all entries made in that column, each with its own check box", topped by a "(Select All)" checkbox; clearing it then ticking individual entries is the basic filter flow, confirmed by OK ([Source](https://www.dummies.com/article/technology/software/microsoft-products/excel/how-to-use-autofilter-in-excel-2019-259697/)).
- A "Search box" sits above the list: "Use the Search box to enter text or numbers on which to search", with "Select and clear the check boxes to show values" ([Source](https://support.microsoft.com/en-us/excel/quick-start-filter-data-by-using-an-autofilter)).
- The type-specific entry ("Date Filters / Text Filters / Number Filters") opens a submenu; "Point to either Number Filters or Text Filters in the list. A menu appears that allows you to filter on various conditions", then "Choose a condition and then select or enter criteria" with "And" (both must be met) / "Or" (either) combinators, then OK ([Source](https://support.microsoft.com/en-us/excel/quick-start-filter-data-by-using-an-autofilter)).
- "Filter by Color" entry opens a submenu with font-color swatches, fill-color swatches, and cell-icon choices ("Filter by Font Color submenu", "Filter by Cell Icon submenu") sourced from manual or conditional formatting ([Source](https://www.dummies.com/article/technology/software/microsoft-products/excel/how-to-use-autofilter-in-excel-2019-259697/)).
- The dropdown also carries sort commands: "Sort A to Z" via "Alt+A, S, A or Alt+Down arrow key, S" and "Sort Z to A" via "Alt+A, S, D or Alt+Down arrow key, O", plus "Filter by color" ("Alt+Down arrow key, I") and "Filter by number or text" ("Alt+Down arrow key, F") accelerator entries, confirming sort, color-filter, and condition-filter entry points all live in the same menu ([Source](https://support.microsoft.com/en-US/Accessibility/excel/use-a-screen-reader-to-sort-or-filter-a-table-in-excel)).
- "Clear" resets filtering: "remove the filtering by clicking the Clear command button in the Sort & Filter group of the Data tab" (plus per-column "Clear Filter from <Column Name>") ([Source](https://www.dummies.com/article/technology/software/microsoft-products/excel/how-to-use-autofilter-in-excel-2019-259697/)); "To clear a filter from a column: Select the Filter button next to the column heading, and then select Clear Filter from <Column Name>" ([Source](https://support.microsoft.com/en-us/office/filter-data-in-a-range-or-table-01832226-31b5-4568-8806-38c37dcc180e)).
- Date columns group the checkbox list hierarchically: the menu "groups your dates by year, month, and day" with expandable year > month nodes plus the "Date Filters" submenu ([Source](https://www.thebricks.com/resources/guide-how-to-filter-by-date-in-excel-using-ai)).
- A "(Blanks)" checkbox appears at the bottom of the value list "only if the column that you want to filter contains a blank cell" ([Source](https://support.microsoft.com/en-us/office/filter-data-in-a-range-or-table-01832226-31b5-4568-8806-38c37dcc180e)).
- Google Sheets' filter popup is structurally different: sections are "Sort A→Z" / "Sort Z→A", "Sort by color", "Filter by condition" (condition dropdown defaulting to None plus optional custom formula), "Filter by values" (uncheck-to-hide + OK), a search box, and "Filter by color" (fill/text); it closes with OK ([Source](https://support.google.com/docs/answer/3540681?hl=en)); "Filter by values: To hide data points, uncheck the box next to the data point and click OK" ([Source](https://support.google.com/docs/answer/3540681?hl=en)); "Search: Search for data points by typing in the search box" ([Source](https://support.google.com/docs/answer/3540681?hl=en)).
- Sheets also offers "Filter by cell value" directly from the cell right-click menu, bypassing the popup ([Source](https://support.google.com/docs/answer/3540681?hl=en)).

### Inferences
- Probable Excel dropdown top-to-bottom order (inferred, not source-confirmed): Sort A–Z / Z–A (or Smallest→Largest / Oldest→Newest variants) → Sort by Color → Clear Filter from… → Filter by Color → Text/Number/Date Filters → Search box → (Select All) + value checkboxes (+ Blanks) → OK / Cancel.
- Sheets has no direct equivalent of Excel's Custom AutoFilter two-condition And/Or dialog; its power-user escape hatch is "Custom formula is" instead.

### Gaps
- No primary source found enumerating the exact ordered list of Excel dropdown rows (e.g., where "Clear Filter" sits relative to sort items); order above is inference.
- Whether Excel's dropdown value list is virtualized past the "first 10,000 unique entries" cap (the cap itself is confirmed in §4) and exact checkbox tri-state behavior were not verified.

## 2. Filter operators per data type (text, number, date)

### Takeaway
Excel exposes a small fixed operator set per type (text: 6 + custom; number: 6 + Between + Top 10 + Above/Below Average + custom; date: 4 fixed + ~20 dynamic relative presets + period picker), all funneling into a two-condition Custom AutoFilter dialog; Sheets exposes a flatter condition list plus custom formulas.

### Cited Findings
- Text Filters submenu: "Equals, Does Not Equal, Begins With, Ends With, Contains, Does Not Contain, Custom Filter", each opening the Custom AutoFilter dialog with that operator preselected ([Source](https://www.dummies.com/article/technology/software/microsoft-products/excel/how-to-use-autofilter-in-excel-2019-259697/)); summarized identically as "Equals, Does Not Equal, Begins With, Ends With, Contains, Does Not Contain, Custom Filter" ([Source](https://www.pk-anexcelexpert.com/data-sort-and-filter/chapter-4/)).
- Number Filters submenu: "Equals, Does Not Equal, Greater Than, Greater Than Or Equal To, Less Than, Less Than Or Equal To, Between, Top 10, Above Average, Below Average, Custom Filter" ([Source](https://www.pk-anexcelexpert.com/data-sort-and-filter/chapter-4/)); "Top 10: Opens the Top 10 AutoFilter dialog box", "Above Average" / "Below Average" apply directly ([Source](https://www.dummies.com/article/technology/software/microsoft-products/excel/how-to-use-autofilter-in-excel-2019-259697/)); also described as "Simple Numeric Conditions (Equals, Does Not Equal, Greater Than, etc.)", "(Top 10…)", "(Above Average)", "(Below Average)", "(Custom Filter…)" ([Source](https://www.excelfunctions.net/excel-autofilter.html)).
- Date Filters: fixed conditions "Equals, Before, After, Between" (taking typed dates / calendar picker) plus dynamic presets "Tomorrow, Today, Yesterday, Next/This/Last Week, Next/This/Last Month, Next/This/Last Quarter, Next/This/Last Year, Year to Date, All Dates in the Period, Custom Filter" ([Source](https://www.pk-anexcelexpert.com/data-sort-and-filter/chapter-4/)); independently corroborated as "Relative Dates: Today, Tomorrow, Yesterday, Next Week, This Week, Last Week, Next Month, This Month, Last Month, Next Quarter, This Quarter, Last Quarter, Year to Date" plus "Specific Conditions: Equals, Before, After, Between" ([Source](https://www.thebricks.com/resources/guide-how-to-filter-by-date-in-excel-using-ai)).
- The full dynamic-date enumeration (Today, Yesterday, Tomorrow, This/Next/Last Week, This/Next/Last Month, This/Next/Last Quarter, This/Next/Last Year, YearToDate, plus All-Dates-in-Period per month January–December and Quarter1–4, Above/Below Average) is confirmed by the xlDynamicFilterCriteria enumeration ([Source](https://bettersolutions.com/excel/macros/enumerations-xldynamicfiltercriteria.htm)).
- Dynamic date presets "are evaluated against your computer's date each time the filter is applied or reapplied", so a saved "This Month" filter stays current ([Source](https://www.pk-anexcelexpert.com/data-sort-and-filter/chapter-4/)); "If you select 'Today' and open the workbook tomorrow, it will show tomorrow's data" ([Source](https://www.thebricks.com/resources/guide-how-to-filter-date-range-in-excel)).
- "All Dates in the Period compares the same month or quarter across every year" (e.g., every January regardless of year) ([Source](https://www.pk-anexcelexpert.com/data-sort-and-filter/chapter-4/)).
- Custom AutoFilter dialog anatomy: "Show rows where:" area with a comparison-operator dropdown + value combo box, "And / Or option button[s]", and a second operator + value row — "Up to 2 criteria can be combined, separated by an 'and' or an 'or'" ([Source](https://www.trainingconnection.com/excel/lessons/filtering-lists.php)); "You can enter up to two criteria and you also have access to the full range of relational operators" (operators shown as "is greater than" / "is less than" phrasing) ([Source](https://www.bettersolutions.com/excel/tables/filtering-custom.htm)).
- Text wildcard support in custom criteria: "You can include the familiar wildcard characters" e.g. "contains" + "o*o" ([Source](https://www.bettersolutions.com/excel/tables/filtering-custom.htm)); wildcard reference: "? (question mark): Any single character… * (asterisk): Any number of characters… ~ (tilde): A question mark or an asterisk", e.g. "sm?th finds 'smith' and 'smyth'", "*east finds 'Northeast' and 'Southeast'" ([Source](https://support.microsoft.com/en-us/office/filter-data-in-a-range-or-table-01832226-31b5-4568-8806-38c37dcc180e)).
- Top 10 AutoFilter dialog has exactly three controls: first dropdown "Top" or "Bottom", a number spinner (default 10, any N), second dropdown "Items" or "Percent" ([Source](https://www.excelfunctions.net/excel-autofilter.html)); "Select 'Top' in the first drop-down, '4' from the spinner control and then 'Items'"; Bottom + Percent variant confirmed ([Source](https://www.bettersolutions.com/excel/tables/filtering-top-10.htm)); Top 10 is "only available for columns that Excel identifies as containing numeric values" ([Source](https://www.excelfunctions.net/excel-autofilter.html)).
- Sheets "Filter by condition" options (UI labels): "Is empty", "Is not empty"; "Text is exactly", "Text contains", "Text does not contain", "Text starts with", "Text ends with"; "Greater than, less than", "Greater than or equal to, less than or equal to", "Equal to", "Not equal to", "Between", "Not between"; "Date is", "Before/After a certain date"; plus "Custom formula is" ([Source](https://sheetsformarketers.com/google-sheets-filter/)); "Filter by condition: Choose conditions or write your own custom formulas", e.g. "Custom formula is" + "=COUNTIF(data_range, data_range)=1" for unique values, "=OR(REGEXMATCH(…))" for multi-text match ([Source](https://support.google.com/docs/answer/3540681?hl=en)); Sheets can also "filter cells that have valid or invalid data validation rules" ([Source](https://support.google.com/docs/answer/3540681?hl=en)).
- Sheets backend condition enum (canonical capability list): NUMBER_GREATER, NUMBER_GREATER_THAN_EQ, NUMBER_LESS, NUMBER_LESS_THAN_EQ, NUMBER_EQ, NUMBER_NOT_EQ, NUMBER_BETWEEN, NUMBER_NOT_BETWEEN, TEXT_CONTAINS, TEXT_NOT_CONTAINS, TEXT_STARTS_WITH, TEXT_ENDS_WITH, TEXT_EQ, TEXT_IS_EMAIL, TEXT_IS_URL, DATE_EQ, DATE_BEFORE, DATE_AFTER, DATE_ON_OR_BEFORE, DATE_ON_OR_AFTER, DATE_BETWEEN, DATE_NOT_BETWEEN, DATE_IS_VALID, ONE_OF_RANGE, ONE_OF_LIST, BLANK, NOT_BLANK, CUSTOM_FORMULA, BOOLEAN, TEXT_NOT_EQ, DATE_NOT_EQ, FILTER_EXPRESSION ([Source](https://github.com/googleapis/google-api-php-client-services/blob/main/src/Sheets/BooleanCondition.php)).
- Excel color/condition exclusivity: "you can filter by a list of numbers, or a criteria, but not by both; you can filter by icon or by a custom filter, but not by both" per column ([Source](https://support.microsoft.com/en-us/office/filter-data-in-a-range-or-table-01832226-31b5-4568-8806-38c37dcc180e)).
- Mixed-type columns show only one condition submenu: "only one type of filter command is available for each column… the command that is displayed is the data type that occurs the most" (e.g., 3 numbers + 4 texts → Text Filters) ([Source](https://support.microsoft.com/en-us/office/filter-data-in-a-range-or-table-01832226-31b5-4568-8806-38c37dcc180e)).

### Inferences
- Excel operator labels in the submenu use Title Case short forms ("Greater Than") while the Custom AutoFilter dialog uses phrasal forms ("is greater than"); a spec should pin both strings per surface.
- Sheets' UI condition labels (e.g., "Text contains") are display strings over the API enum (e.g., TEXT_CONTAINS); TEXT_IS_EMAIL / TEXT_IS_URL / DATE_IS_VALID exist in the backend but their presence in the interactive dropdown is unconfirmed.

### Gaps
- No source confirmed the complete verbatim Sheets "Filter by condition" dropdown list (relative-date options like "Date is exactly/in the past week" variants, blank/not-blank placement); the list above merges two secondary sources.
- Top-10 tie behavior (whether ties beyond N are included) was not verified from any source.

## 3. Multi-level sort (dialog fields, options)

### Takeaway
Excel's Sort dialog supports up to 64 ordered levels, each a Column × Sort On × Order triple with copy/delete/reorder, plus header-row, case-sensitivity, orientation, custom-list, and sort-by-color options; Sheets offers a simpler stacked-rule dialog ("Add another sort column") plus one-click sheet sorts.

### Cited Findings
- Opening: "On the Data tab, in the Sort & Filter group, select Sort" opens the Sort dialog ([Source](https://support.microsoft.com/en-us/excel/sort-data-in-a-range-or-table-in-excel)); alternates: Home > Editing > "Sort & Filter option, and choose Custom Sort", or "Data tab, click Sort" ([Source](https://www.techrepublic.com/article/how-to-sort-data-by-multiple-columns-in-excel/)); keyboard "Alt, A, S, S" ([Source](https://www.pk-anexcelexpert.com/data-sort-and-filter/chapter-1/)).
- Level row fields: "under Column, in the Sort by box, select the first column"; "Under Sort On, select the type of sort… To sort by text, number, or date and time, select Cell Values. To sort by format, select Cell Color, Font Color, or Cell Icon"; "Under Order, select how you want to sort" ([Source](https://support.microsoft.com/en-us/excel/sort-data-in-a-range-or-table-in-excel)).
- Order vocab per type: "For text values, select A to Z or Z to A. For number values, select Smallest to Largest or Largest to Smallest. For date or time values, select Oldest to Newest or Newest to Oldest. To sort based on a custom list, select Custom List" ([Source](https://support.microsoft.com/en-us/excel/sort-data-in-a-range-or-table-in-excel)).
- Level management: "To add another column to sort by, select Add Level"; "To copy a column to sort by, select the entry and then select Copy Level"; "To delete a column to sort by, select the entry and then select Delete Level" ("You must keep at least one entry in the list") ([Source](https://support.microsoft.com/en-us/excel/sort-data-in-a-range-or-table-in-excel)).
- Priority: "To change the order in which the columns are sorted, select an entry and then select the Up or Down arrow next to the Options button… Entries higher in the list are sorted before entries lower in the list" ([Source](https://support.microsoft.com/en-us/excel/sort-data-in-a-range-or-table-in-excel)); semantics: sort Region first "then by Sales… Note that since it sorts the Region column first when the Sales column is sorted, the Region column remains unchanged" (stable tie-breaking) ([Source](https://trumpexcel.com/multiple-level-sorting-excel/)).
- Capacity: "You can sort by up to 64 columns" ([Source](https://support.microsoft.com/en-us/excel/sort-data-in-a-range-or-table-in-excel)); "can nest up to 64 levels" ([Source](https://www.pk-anexcelexpert.com/data-sort-and-filter/chapter-1/)).
- Header handling: "My data has headers" checkbox — "ensure that 'My data has headers' option is checked" so headers stay put ([Source](https://trumpexcel.com/multiple-level-sorting-excel/)); "By default… Excel assumes… a header row… not to be reordered"; without headers "specify the sorting keys by column letter, and… deselect the My Data Has Headers check box" ([Source](https://www.dummies.com/article/sorting-on-multiple-fields-in-an-excel-2016-data-list-140205)); "To exclude the first row… select My data has headers… To include the first row… clear My data has headers" ([Source](https://support.microsoft.com/en-us/excel/sort-data-in-a-range-or-table-in-excel)).
- Options dialog: "In the Sort dialog box, select Options… In the Sort Options dialog box, select Case sensitive… Select OK twice" ([Source](https://support.microsoft.com/en-us/excel/sort-data-in-a-range-or-table-in-excel)).
- Left-to-right sort: "under Orientation, select Sort left to right… Under Row, in the Sort by box, select the row" (generally row 1); "Tables don't support left to right sorting… first convert the table to a range" ([Source](https://support.microsoft.com/en-us/excel/sort-data-in-a-range-or-table-in-excel)).
- Sort by color: under Sort On choose Cell/Font Color or Cell Icon, then "select a cell color, font color, or cell icon" under Order and direction "On Top… On Bottom for a column sort, and On Left… On Right for a row sort"; "There is no default cell color, font color, or icon sort order. You must define the order" ([Source](https://support.microsoft.com/en-us/excel/sort-data-in-a-range-or-table-in-excel)); Sort On options enumerated as "Cell Values (default), Cell Color, Font Color, and Conditional Formatting Icon" ([Source](https://www.contextures.com/excelsortmultiplecolumns.html)).
- Custom lists: "Excel ships with day and month lists; add your own under File > Options > Advanced > Edit Custom Lists, typing one entry per line or importing them from a range" ([Source](https://www.pk-anexcelexpert.com/data-sort-and-filter/chapter-1/)); official flow: enter values top-to-bottom, select range, "File > Options > Advanced > General > Edit Custom Lists… select Import"; constraints: "based only on a value (text, number, and date or time)… cannot create a custom list based on a format"; "maximum length… 255 characters, and the first character must not begin with a number" ([Source](https://support.microsoft.com/en-us/excel/sort-data-in-a-range-or-table-in-excel)).
- Sort-warning guardrail: sorting a single column pops a "Sort Warning dialog box… Make sure 'Expand the selection' is selected… not just data in the [single] column" vs "Continue with the current selection" ([Source](https://trumpexcel.com/multiple-level-sorting-excel/)); "Excel will warn you… press the Expand the selection option, otherwise select Continue with the current selection" ([Source](https://support.microsoft.com/en-us/excel/sort-data-in-a-range-or-table-in-excel)).
- Header-row sort entry point in tables: "filter button at the top of each table column" offers sort order directly ([Source](https://support.microsoft.com/en-us/excel/sort-data-in-a-range-or-table-in-excel)).
- Sheets multi-sort: "Click Data > Sort range > Advanced range sorting options… If your columns have titles, click Data has header row. Select the column… and choose a sorting order. To add another sorting rule, click Add another sort column. Click Sort" ([Source](https://support.google.com/docs/answer/3540681?hl=en)).
- Sheets one-click sorts: "At the top, right-click the letter of the column… Click Sort sheet A to Z or Sort sheet Z to A" ([Source](https://support.google.com/docs/answer/3540681?hl=en)); "Sort by color: Choose which text or fill color to filter or sort by. Cells with the color you choose to sort by will move to the top" (conditional-formatting colors yes, alternating colors no) ([Source](https://support.google.com/docs/answer/3540681?hl=en)).
- Sheets filter-level sorts are ordered specs: "A filter can have multiple sort specifications… applied in the specified order" via SortSpec dimensionIndex + sort order ([Source](https://developers.google.com/workspace/sheets/api/guides/filters)).

### Inferences
- Excel's dialog is the only surface supporting case-sensitive and custom-list sorts; quick-sort buttons and header-dropdown sorts are single-key only — a viewer spec should route multi-key/color/custom sorts to a dialog, not the dropdown.
- Sheets has no confirmed equivalent of case-sensitive sort, custom-list sort, or left-to-right sort in its documented UI; treat as absent pending verification.

### Gaps
- Sheets' "Advanced range sorting options" maximum rule count and whether sort rules there persist (vs. one-shot) were not confirmed.
- Whether Sheets quick sorts are stable and how they treat blanks vs. Excel was not found in sources.
- Excel's exact tie/blank placement in multi-level sorts was not covered by sources.

## 4. Filter state communication (icons, row hiding, messages)

### Takeaway
Excel signals filter state through the header-button glyph (arrow vs. funnel) plus hover tooltips, hides whole rows, and requires explicit reapply after data changes; Sheets shows a filtered-range status count ("N of M rows") and persists filter settings per range/filter view.

### Cited Findings
- Icon states: "A drop-down arrow means that filtering is enabled but not applied. When you hover over the heading… a screen tip displays '(Showing All)'. A Filter button [funnel] means that a filter is applied. When you hover over the heading of a filtered column, a screen tip displays the filter applied to that column, such as 'Equals a red cell color' or 'Larger than 150'" ([Source](https://support.microsoft.com/en-us/office/filter-data-in-a-range-or-table-01832226-31b5-4568-8806-38c37dcc180e)); table flow: "Select OK. The column header arrow changes to a Filter icon. Select this icon to change or clear the filter" ([Source](https://support.microsoft.com/en-us/office/filter-data-in-a-range-or-table-01832226-31b5-4568-8806-38c37dcc180e)); dummies corroborates "adding a cone filter icon to the column's AutoFilter button" ([Source](https://www.dummies.com/article/technology/software/microsoft-products/excel/how-to-use-autofilter-in-excel-2019-259697/)).
- Row hiding: "When you filter data, entire rows will be hidden if the values in one or more columns don't meet the filtering criteria" ([Source](https://support.microsoft.com/en-US/Excel/use-autofilter-to-filter-your-data)); "Filtered data displays only the rows that meet criteria… and hides rows that you do not want displayed" ([Source](https://support.microsoft.com/en-us/office/filter-data-in-a-range-or-table-01832226-31b5-4568-8806-38c37dcc180e)).
- Additive across columns: "You can also filter by more than one column. Filters are additive, which means that each additional filter is based on the current filter and further reduces the subset of data" ([Source](https://support.microsoft.com/en-us/office/filter-data-in-a-range-or-table-01832226-31b5-4568-8806-38c37dcc180e)); exception: "some filters (top and bottom ten, above and below average) are based on the original range of cells… you'll see the top ten values of the whole list, not the top ten values of the subset of the last filter" ([Source](https://support.microsoft.com/en-us/excel/get-started/filter-data-in-a-range-or-table-in-excel)).
- Scoped value lists: "When you apply a filter to a column, the only filters available for other columns are the values visible in the currently filtered range" ([Source](https://support.microsoft.com/en-us/office/filter-data-in-a-range-or-table-01832226-31b5-4568-8806-38c37dcc180e)).
- Scale caps: "Only the first 10,000 unique entries in a list appear in the filter window" ([Source](https://support.microsoft.com/en-us/office/filter-data-in-a-range-or-table-01832226-31b5-4568-8806-38c37dcc180e)); "You can apply filters to only one range of cells on a sheet at a time" ([Source](https://support.microsoft.com/en-us/office/filter-data-in-a-range-or-table-01832226-31b5-4568-8806-38c37dcc180e)).
- Reapply semantics: "reapply a filter to get up-to-date results" when "Data has been added, modified, or deleted… Values returned by a formula have changed and the worksheet has been recalculated"; filters do not auto-refresh on data change ([Source](https://support.microsoft.com/en-us/office/filter-data-in-a-range-or-table-01832226-31b5-4568-8806-38c37dcc180e)).
- Clear vs. remove ladder: per-column "Clear Filter from <Column Name>"; Data-tab "Clear" clears all criteria; toggling "Data > Filter" off "will remove the filters from all the columns… and show all your data" (removes arrows entirely) ([Source](https://support.microsoft.com/en-us/office/filter-data-in-a-range-or-table-01832226-31b5-4568-8806-38c37dcc180e)).
- Filtered-data side effects: "you can copy, find, edit, format, chart, and print the subset of filtered data without rearranging or moving it"; "When you use the Find dialog box to search filtered data, only the data that is displayed is searched" ([Source](https://support.microsoft.com/en-us/office/filter-data-in-a-range-or-table-01832226-31b5-4568-8806-38c37dcc180e)).
- Sheets status message: "Once filtered, at the bottom right users can find the number of rows being displayed out of the total rows in the table" ([Source](https://support.google.com/docs/answer/3540681?hl=en)).
- Sheets persistence: "Your filter settings are saved, ensuring consistent filtering even if the data you filter on is removed. To reset filter settings, you can remove the filter from your data range"; "When you add a filter, anyone with access to your spreadsheet will find the filter too" (basic filter is shared, unlike filter views) ([Source](https://support.google.com/docs/answer/3540681?hl=en)).
- Sheets filter views: "Save multiple filters… Name your filter… Let multiple people find different filter views at the same time… Share different filters… Make a copy"; "You can only apply one filter view at a time"; view-only users get a temporary unsaved view; changes autosave via "Save View"; "Copy the URL" shares a view ([Source](https://support.google.com/docs/answer/3540681?hl=en)).
- API-level Sheets model: "Filters don't change the data values… temporarily hide or sort"; "A sheet can have multiple filter views saved, but you can only apply one at a time… cannot apply both [basic filter and filter view] simultaneously on the same data range"; per-column criteria combine hiddenValues lists and boolean conditions, with "sortSpecs… applied in the specified order" ([Source](https://developers.google.com/workspace/sheets/api/guides/filters)).

### Inferences
- Excel has no confirmed persistent "N of M rows" status readout comparable to Sheets' bottom-right count; state is conveyed via glyphs/tooltips and hidden-row gaps — a viewer spec should add an explicit status line since Excel's native signaling is glyph-only.
- Reapply behavior implies a viewer must mark filter results stale on data/formula change and offer explicit Reapply rather than silent auto-refresh (Excel model), whereas Sheets' "settings saved" model suggests persisting criteria across data edits.

### Gaps
- Blue-highlighted row numbers / non-contiguous row-header rendering for hidden rows (commonly described in Excel lore) had no citable source in this pass.
- Sheets' exact header-glyph change for filtered columns (funnel fill state) was not confirmed from sources.
- No source confirmed an Excel status-bar or dialog message stating match counts.

## 5. Keyboard and ARIA patterns

### Takeaway
Excel documents a full keyboard map (toggle, open, sort, reapply, checkbox toggling) and screen-reader flows that expose inconsistent menu announcements across SRs; for ARIA, the applicable norms are the W3C APG Menu/Menu-button and Listbox patterns (roles, roving focus, type-ahead, announcements), though the actual DOM roles of Excel-for-web/Sheets popups are unverified.

### Cited Findings
- Excel keyboard map: "Turn the AutoFilter dropdown menu in a column heading off and on: Ctrl+Shift+L"; "Open the AutoFilter dropdown menu from a column header: Alt+Down arrow key"; "Sort smallest to largest, or A to Z: Alt+A, S, A or Alt+Down arrow key, S"; "Sort largest to smallest, or Z to A: Alt+A, S, D or Alt+Down arrow key, O"; "Open the Sort dialog box: Alt+A, S, S or Alt+H, S, U"; "Reapply a sort after you change the data: Ctrl+Alt+L or Alt+A, Y, 3"; "Filter by color: Alt+Down arrow key, I"; "Filter by number or text: Alt+Down arrow key, F" ([Source](https://support.microsoft.com/en-US/Accessibility/excel/use-a-screen-reader-to-sort-or-filter-a-table-in-excel)).
- In-menu operation: "use the Down arrow key to move to Number/Text Filters and press Enter"; "Use Spacebar to clear or select a filter value checkbox"; "press the Tab key until you hear 'OK button,' and then press Enter" ([Source](https://support.microsoft.com/en-US/Accessibility/excel/use-a-screen-reader-to-sort-or-filter-a-table-in-excel)).
- Screen-reader announcements (confirmed inconsistency): opening the dropdown is heard as "Menu" (Narrator), "Context menu" (JAWS), "Unknown" (NVDA); the condition submenu opens with "Equals"; the dialog announces "Custom AutoFilter" ([Source](https://support.microsoft.com/en-US/Accessibility/excel/use-a-screen-reader-to-sort-or-filter-a-table-in-excel)).
- APG Menu keyboard norm: "When a menu opens… keyboard focus is placed on the first item"; "Tab and Shift+Tab… move focus out of the menu… and close all menus"; arrows move within; "Enter… activates the item and closes the menu" or opens a submenu; "Escape: Close the menu… and return focus to the element… from which the menu was opened"; "Any key that corresponds to a printable character (Optional): Move focus to the next item… whose label begins with that printable character" ([Source](https://www.w3.org/WAI/ARIA/apg/patterns/menubar/)).
- APG menu semantics: container role `menu`/`menubar` labelled via `aria-labelledby`/`aria-label`; items as `menuitem`/`menuitemcheckbox`/`menuitemradio` with `aria-checked` when checked, `aria-disabled` (focusable-but-unactivatable); focus via roving `tabindex` or `aria-activedescendant` ([Source](https://www.w3.org/WAI/ARIA/apg/patterns/menubar/)).
- Menu-button trigger norm: Down/Space/Enter opens and focuses first item, Up opens and focuses last; Esc closes and refocuses the button; A–Z moves to next same-initial item ([Source](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/examples/menu-button-actions-active-descendant/)).
- APG Listbox norm (applies to the checkbox value list + search): focus lands on selected option else first; Up/Down/Home/End move; "Type-ahead is recommended for all listboxes, especially those with more than seven options"; Space toggles in the modifier-free multi-select model; `listbox`/`option` roles with `aria-selected`, `aria-setsize`/`aria-posinset` for virtualized sets; "If selecting or unselecting all options is an important function, implementing separate controls… such as buttons for 'Select All' and 'Unselect All', significantly improves accessibility" — matching Excel's (Select All) row ([Source](https://www.w3.org/WAI/ARIA/apg/patterns/listbox/)).
- Composite-widget focus norm: "tab and shift+tab keys move focus from one UI component to another while… arrow keys… move focus inside"; "The tab sequence should include only one focusable element of a composite" (roving tabindex); disabled items may stay focusable with `aria-disabled="true"` for discoverability ([Source](https://www.w3.org/WAI/ARIA/apg/practices/keyboard-interface/)).
- Dialog pattern implication for Sort/Custom/Top-10 dialogs: initial focus in dialog, Tab-trapped cycle, Esc cancels, Enter confirms — standard APG dialog behavior consistent with the documented "Tab … until you hear 'OK button,' and then press Enter" flow ([Source](https://support.microsoft.com/en-US/Accessibility/excel/use-a-screen-reader-to-sort-or-filter-a-table-in-excel)).

### Inferences
- The NVDA "Unknown" announcement for the Excel dropdown indicates the trigger/menu lacks a proper `menu` role mapping in that path; a new viewer should use an explicit `menu` role with `aria-labelledby` to the header button and verify announcements in Narrator/JAWS/NVDA rather than copying Excel's mapping.
- Excel's value list maps best to a multi-select `listbox` (checkboxes as `option` + `aria-selected`, or native checkboxes), the condition submenus to `menu`/`menuitemradio`, and the search box to a filtering textbox with `aria-controls` on the list; live-region announcements ("N of M values shown", "filter applied to Column X") should be added since neither suite documents them.

### Gaps
- No citable source for Google Sheets' filter/sort keyboard shortcuts or its screen-reader announcement strings; Sheets a11y behavior is unverified.
- Actual DOM roles/attributes used by Excel for the web and Google Sheets filter popups were not inspected (no DOM teardown source found); ARIA guidance above is normative (what to apply), not descriptive (what ships).
- No source on focus-return behavior after OK/Cancel in either product's filter popup beyond the generic APG norm.
