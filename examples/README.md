# Examples

Standalone projects that install `officeview` from npm.

| Example | What it shows |
| --- | --- |
| [vite-react](vite-react) | Vite + React: file picker, drag and drop, the viewer worker (`worker: { format: 'es' }`) |
| [nextjs](nextjs) | Next.js App Router: a client component, the stylesheet, the viewer worker (Turbopack and webpack) |

Each one runs with `npm install && npm run dev`.

Smaller recipes (progress bars, your own Present button, thumbnails, headless
search, custom loading states, brand colours, per-user watermarks) run live on
the [Examples page](https://julianshen.github.io/officeview/examples/), next to
their source in [`site/src/examples`](../site/src/examples).
